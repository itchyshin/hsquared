## What `public_covered_count` counts

`public_covered_count` is **7**: the covered *public modelling capabilities* —
the default univariate path, four covered opt-in pedigree targets, the
default-route multivariate t=2 unstructured model (G10), plus opt-in genomic
GREML (0.7). Numerous surfaces assert the live count; this is the list that
number refers to, so the assertion is checkable.

| # | Capability | Route |
| --- | --- | --- |
| 1 | v0.1 univariate Gaussian animal model | default `engine = "fit"` |
| 2 | common-environment two-effect model | opt-in `target = "two_effect"` |
| 3 | arbitrary-N independent `(1 \| g)` multi-effect model | opt-in `target = "multi_effect"` |
| 4 | random-regression (reaction-norm) k=2 model | opt-in `target = "random_regression"` |
| 5 | direct–maternal correlated 2×2 G model | opt-in `target = "direct_maternal"` |
| 6 | multivariate Gaussian animal model (t=2 unstructured) | default-route `cbind()` / explicit `target = "multivariate"` |
| 7 | genomic GREML (opt-in validation-scale) | explicit `target = "genomic"` |

Ordinals are flip order. **Capabilities 2–5 and 7 are opt-in; capability 6 is
default-routed but validation-scale / experimental.** Write "the 7th
`public_covered_count`" for genomic GREML. Default genomic activation is **not**
this claim.

This is **not** the `validation_status()` covered-row count (**4** live, on a
different grouping — see `39-h0-univariate-coverage-flip.md`), and not the
engine ladder's (`HSquared.jl`: 13 covered + 3 covered_external of 56 rows).
Engine-covered ≠ R-public-covered.

**Known gap (not resolved here).** Capabilities 4 and 5 have **no dedicated
`validation_status()` row**; their evidence lives in this register, in
`capability-status.md`, and on the twin's `V3-RR-REML` / `V4-DIRECT-MATERNAL`
rows. The attach-time advice in `zzz.R` ("report point estimates only for
covered rows in `validation_status()`") therefore does not reach them. Adding
rows would be a covered-status change and is out of scope for a wording scrub.
