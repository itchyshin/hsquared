# Bounded Gaussian FA R opt-in, candidate report

## 1. Goal

Make the four-trait, one-factor Gaussian pedigree FA fit usable through explicit R expert controls while keeping its validation limits visible.

## 2. Implemented

The R bridge now accepts exactly this complete-response cell with trait intercepts and an estimated unstructured residual covariance. The fit returns genetic covariance, uniqueness, genetic correlations, fixed effects, breeding values, and diagnostics. Julia's normalized pedigree IDs are checked against R's incidence-column IDs before fitting. Formula `cov = fa()` remains reserved. The public vignette shows the exact call and its iteration limit.

## 3a. Decisions and Rejected Alternatives

The acceptance fixture fixes `K = 1`; automatic rank selection is a separate task. Raw loading inference is withheld because loadings are rotation dependent. The expert-control target is intentionally narrow. No broad FA or release claim follows from an engine-covered row.
